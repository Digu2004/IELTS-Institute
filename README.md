# IELTS Institute React Project

## Description
Welcome to a fictional IELTS Insitute homepage built with React JS and Bootstrap!  
This project showcases a clean and modern design with:  
- A **Navbar** with logo and menu links for easy navigation  
- A **Hero Section** with headline, subtext, call-to-action button, and banner image  
- **Feature Cards** highlighting services like Speaking Practice, Mock Tests, AI Band Score, and Study Materials  
- **Student Testimonials** to show feedback from learners  
- A **Footer** with quick links and contact info
